# Word/PDF competition artifacts

This folder archives the generated Word/PDF materials for FocusGuard - AI Tài Năng Việt 2026, Bảng A.

## Privacy
This repository is public. The unredacted final submission contains a minor student's date of birth, phone number and email, so that private version is intentionally kept off GitHub.

The public archive includes:
- all non-sensitive generated Word/PDF working materials;
- the official-template working copies;
- a redacted FINAL DOCX/PDF suitable for public source control.

The unredacted FINAL submission remains in the team's Google Drive for submission to the organizer.
